# TaskFlow - Gestion de Tâches

Une application web Django pour gérer vos tâches quotidiennes, projets académiques et priorités personnelles.

##  Description

TaskFlow est une application de gestion de tâches développée avec Django. Elle permet aux utilisateurs de créer, organiser et suivre leurs tâches avec un tableau de bord intuitif, des filtres de recherche et un système de priorisation.

**Fonctionnalités principales :**
- Authentification sécurisée (inscription/connexion/déconnexion)
- Tableau de bord avec statistiques (total, en cours, terminées)
- CRUD complet des tâches (Créer, Lire, Modifier, Supprimer)
- Recherche par titre/description
- Filtrage par statut et priorité
- Tri par date, priorité ou création
- Protection des données par utilisateur

##  Technologies

**Backend**
- Django 4.2.30
- MySQL 8.0
- Python 3.13

**Frontend**
- Bootstrap 5
- Crispy Forms
- HTML /CSS

##  Sécurité

- Authentification Django intégrée
- Protection CSRF sur tous les formulaires
- Isolation des données par utilisateur
- Validation des mots de passe
- Hachage sécurisé des mots de passe
